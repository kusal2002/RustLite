# CSS-001: CSS parsing, selectors, cascade, and computed values (first layer)

- **Reference browser:** Chromium 152.0.7977.130 (the Claude desktop app's built-in
  browser pane; UA and `devicePixelRatio` (1) recorded in `tests/style/oracle.txt`)
- **OS:** Windows 11 Pro 10.0.26200
- **Observation tool:** `scripts/oracle/server.py` `/style` page: each fixture is rendered
  in an 800×600 `srcdoc` iframe and `getComputedStyle` is read for every element.
  **REA was not used**: computed styles need only `getComputedStyle`, no CDP session.
- **Date:** 2026-10-16

## Scenario

11 fixtures in `tests/style/*.html`: UA defaults for common elements, specificity
/ `!important` / inline styles / source order, all four combinators and seven
attribute operators, structural and link pseudo-classes, `inherit` / `initial` /
`unset` / `currentcolor`, every supported length unit (`em`, `rem`, `%`, `pt`,
`in`, `cm`, `mm`, `pc`, `vw`, `vh`, `vmin`, `vmax`) and font-size keywords,
color syntaxes (named, hex 3/4/6/8, `rgb()`/`rgba()` legacy and modern, `hsl()`),
margin/padding/border/overflow shorthands, font family/weight/style, invalid
declaration recovery, and `display` values including root blockification.

## Direct observations

- Expected values (`tests/style/*.styles`) are the browser's resolved values.
- First comparison: 8/11 fixtures matched. The three differences were:
  1. 8-bit alpha serialization: `#ff000080` → `rgba(255, 0, 0, 0.5)` (shortest
     decimal that round-trips to the same 8-bit alpha, per CSSOM).
  2. Initial `font-family` is `"Times New Roman"` on this platform, and a quoted
     family named `serif` serializes quoted (`"serif"`).
  3. `input` and `button` have UA appearance styles: 13.3333px font size,
     2px inset/outset borders, padding (1px 2px / 1px 6px), backgrounds
     (white / rgb(240, 240, 240)), `input` overflow `clip`, `button` text-align center.
- All three were fixed (the third by adding evidence-cited rules to `ua.css`);
  now **11/11** match.
- `srcdoc` iframe documents are always in no-quirks mode, so quirks-mode selector
  matching cannot be observed this way; it is covered by a unit test instead.

## Inferences

- Resolved values for `width`, `height`, and `auto`/percentage margins are
  used values in browsers; fixtures avoid them until layout exists.

## Unknowns / not covered

- `@media`, `@import`, `@supports`, `@font-face` (skipped), `<link rel=stylesheet>`
  (needs networking), `:not()`/`:is()`/`:where()`/`:nth-*()`, custom properties and
  `var()`, `calc()`, `ex`/`ch` units, the `font` shorthand, `background` beyond a
  single color, monospace font-size scaling, `th`/`center` `-internal-center`
  alignment, macOS/Linux default fonts (not observed).

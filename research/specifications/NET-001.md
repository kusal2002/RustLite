# NET-001: HTTP(S) loading, navigation, and subresources

- **Date:** 2026-10-16
- **OS:** Windows 11 Pro 10.0.26200
- **Reference browser for visual comparison:** Chromium 152 (built-in browser pane)
- **REA was not used**: behavior was verified with local test servers and
  real requests to public test sites.

## Automated evidence (no external network)

- `crates/net/tests/fetch.rs` (local HTTP server): charset from `Content-Type`,
  redirects (single, relative `Location`, 10-hop chain), redirect loop and 11
  hops → `ERR_TOO_MANY_REDIRECTS`, redirect to `file:` →
  `ERR_UNSAFE_REDIRECT`, missing `Location`, 404 with body, 5 MiB body over the
  4 MiB stylesheet limit, timeout, refused connection, HTTPS to a plain-HTTP
  port → TLS error, loader cancellation of a queued job.
- `crates/browser-core/tests/navigation.rs` (local HTTP server, real `Loader`):
  document + linked stylesheet (computed color changes) + network image
  (laid out at 4×4); redirect commits the final URL; a superseded slow
  navigation whose result arrives later is ignored and leaves no history
  entry; 404 shows the server page; refused connection shows RustLite's error
  page; `text/plain` renders as text, not markup; clicking a link (hit test →
  `link_at`) navigates, and Back returns.
- `browser-core` unit tests: address input parsing, error-page escaping,
  `file:`/`javascript:`/`data:` blocked for page-initiated navigation,
  file history back/forward.

## Findings that changed the code

Rendering example.com exposed three unsupported CSS features used by the
page; all were added and verified with new Chromium fixtures
(`tests/style/font-shorthand`, `tests/layout/min-max-sizes`):
the `font` shorthand, `min-/max-width/height` (including replaced elements
keeping their ratio), and `light-dark()` (light scheme only).

## Not covered

Chromium's version of example.com shows extra translated paragraphs and an
icon added by the page's script (`/s.js`); RustLite does not run JavaScript.
No automated TLS certificate test runs offline (needs a local TLS server with
a test CA; the badssl checks above are manual).
